Adelina Lipșa, CV site, design plan

It didn’t exist,
so I built it.

The site opens on a CV that doesn’t exist yet. Press play and watch it get built: a cursor, real code typing, components snapping in, colour flooding the page. Everything else backs up that one moment.

Broken on purpose.Unbuilt is raw HTML on blueprint. Built is the real identity.
One show.The build is the loud part. Everything around it stays calm.
Both halves, equally.Product owner and full-stack developer. Neither one is a footnote.
Every tile has a before.Didn’t exist: the problem. Now: the thing.
Funny lives in the words.Microcopy, errors, the build narration. No mascots, no props.
Never in the way.Every joke has a skip link one tap away.
