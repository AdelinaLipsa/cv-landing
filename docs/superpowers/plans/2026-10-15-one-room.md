## Design

### The idea
The Off duty desk scene is the site's signature, but it only shows up once. Everything new is made from the same materials (`plastic()`, the same light and environment, the same ACES exposure), with the same hand-drawn notes in `--naruto` pink. The whole site should read as one room. Nothing that's already there is removed or restyled: the HTML buttons, chips and cards stay where they are and keep working exactly as they do now. The 3D sits next to them and reacts to them.

### 1. The ending: "the desk where you reach her"
Today: the heading, one line and three buttons, then about 300px of empty space.
New: on desktop (≥1000px) the ending becomes two columns, like Off duty: the text and buttons on the left, a 3D scene on the right (height 380px). On phones the scene sits under the buttons (height 260px). Each button gets its own object, in the same left-to-right order:

| Button | Object | When the button is hovered or focused, or the object is pointed at | Clicking the object |
|---|---|---|---|
| Message me | beige 90s desk phone with a coiled cord | the handset rattles on its cradle and the cord wobbles | `ui.contact()` |
| Download the PDF | dot-matrix printer with tractor-feed paper | paper with her name and role on it feeds out of the printer | downloads `profile.pdf` |
| LinkedIn | Rolodex | the cards flip until hers faces front (`Adelina Lipșa` / `in/adelina-lipsa`) | opens `profile.linkedin` |

- The oiia cat (`/models/oiia-cat.glb`, already in the repo) sits on the printer. It spins once each time any object acts. That's the call-back to Off duty.
- There's one hand-drawn note for each object, in the existing `.note` style. Proposed copy: "ring me", "print me out", "my card". **The cv-copywriter agent signs off on these before they ship.**
- The camera doesn't move: no drag and no zoom (that's what Off duty is for). There's a slow idle breathing: the printer head ticks now and then and the Rolodex rocks a little.
- With reduced motion, the scene renders one still frame. Hover still sets the "acted" pose, as a single re-render with no animation.
- The empty `margin-bottom: 140px` of `.outro` shrinks to whatever the dock needs, because the scene now fills that space.

### 2. Skills: the parts cabinet
Today: a title, the role picker, then 7 white cards of chips.
New: a small-parts organiser cabinet (beige frame, smoky see-through drawers, Dymo-style label tape on each front) next to the title and picker on desktop (right column, 300px tall), and between the picker and the cards on phones (220px tall). The cards don't change.

- One drawer per entry in `layers` (`content/skills.ts`). The drawer grid follows the card order: row 1 is Product Management at full width, then pairs: Agile | Payments, Analytics | Development, DevOps | Tools.
- Each drawer holds `chips.length` tiny parts (instanced little resistors). Parts for chips the picked role used are amber `#F5B53F`. The rest are beige.
- With **Everything** picked, every drawer is shut and the cabinet just stands there with its labels. **Pick a role** and the drawers that role used slide out. How far each one opens depends on how much of that drawer the role used (minimum 35%, so any drawer that was touched is clearly open). Drawers the role didn't touch stay shut.
- Hovering a chip makes its drawer pop out a few millimetres. Hovering a drawer lights the matching card: the card gets `data-lit`, styled like the picker's existing `data-lit`.
- The labels are canvas textures: dark navy tape (`#2A2760`) with raised white capitals, the way label-maker tape looked.

## Global Constraints

- No new npm dependencies. three, motion and ogl are already installed.
- New 3D objects are **built in code** from the same `plastic()` material as the computer, so they match. No downloaded models apart from the cat that's already in the repo.
- three.js is imported dynamically and only when the scene's host scrolls within `rootMargin: "300px"`. Nothing renders while it's off screen or `document.hidden`, the same as `RetroComputer`.
- On touch (`pointer: coarse`): pixel ratio ≤1.5, no antialias, no `transmission` (use `opacity` instead).
- `prefers-reduced-motion`: one still frame, no loops.
- Every canvas host has `role="img"` and an `aria-label` describing the scene. The real controls stay HTML buttons and links.
- Dark mode (`[data-theme="dark"]`) has to look right: transparent canvas, and the notes use `var(--ink)` and `var(--paper)` like `.noteText`.
- Copy rules (memory `cv-copy-rules`): every user-visible string, including aria-labels, goes through the **cv-copywriter** agent before commit.
- Comment style follows `RetroComputer.tsx`: short, plain-English, explains *why*.
- Commit messages follow the repo's style: one descriptive sentence about what the visitor sees, no `feat:` prefixes. End with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- The dev server's `AGENTS.md` block is re-added by `next dev`. Leave it alone.

## Review Focus

1. **Switching tabs while a scene is mid-animation.** Panes slide with a CSS transform, so the hidden scene has to stop rendering (IntersectionObserver reports it off screen). Expected: no rAF running for the Finale or the Cabinet while on another tab. Pinned in Tasks 2 and 4 with a `data-frames` counter check.
2. **Touch devices have no hover.** Expected: tapping an object fires its action straight away, without a hover first, and tapping a button still works. Pinned in Task 3's phone check.
3. **three.js or the cat model fails to load** (offline, blocked). Expected: the buttons work, the scene area stays empty with no console error loop, and the cat is simply missing. Pinned in Task 2 by blocking the `.glb` URL in DevTools.
4. **A fast pointer leaving a chip or drawer.** Expected: no stuck lit card or popped drawer, because `onHoverEnd` and `pointerleave` always clear. Pinned in Task 5.
5. **Dark mode and reduced motion.** Expected: the scenes are readable on the dark paper, and with reduced motion there's a single frame. Pinned in Task 7's final pass.

**Interfaces:**
- Produces:
  ```ts
  export type Toy = {
    THREE: typeof T; renderer: T.WebGLRenderer; scene: T.Scene; camera: T.PerspectiveCamera;
    reduce: boolean; touch: boolean;
    plastic: (color: number, roughness: number) => T.MeshPhysicalMaterial;
    box: (w: number, h: number, d: number, m: T.Material, x?: number, y?: number, z?: number) => T.Mesh;
    blob: (radius: number) => T.Mesh;           // soft contact shadow on the floor, y = 0.002
    fit: (sphere: T.Sphere, view: T.Vector3, tight?: number) => void; // aims the camera, re-run on resize
    run: (frame: (t: number, dt: number) => boolean | void) => void; // see below
    dispose: () => void;
  };
  export async function toyStage(el: HTMLElement): Promise<Toy>;
  ```
  `run(frame)`: drives rAF only while `el` is in view and the tab is visible. `frame` returns `false` when nothing moved (the loop skips that render). With `reduce`, it renders once and stops. `toy.invalidate()` is not needed. When the scene changes under reduced motion, the caller calls `frame` once and then `renderer.render(scene, camera)` itself.

```ts
import type * as T from "three";

// The room every 3D scene on the site lives in: one studio light, one environment, one 90s plastic.
// Off duty's computer was built here first; the ending and the Skills cabinet reuse it so they look like
// they came out of the same room.
export async function toyStage(el: HTMLElement) {
  const [THREE, { RoomEnvironment }] = await Promise.all([import("three"), import("three/examples/jsm/environments/RoomEnvironment.js")]);
  const reduce = matchMedia("(prefers-reduced-motion: reduce)").matches;
  // Phones: fewer pixels and no antialias; 3x screens make WebGL the heaviest thing on the page.
  const touch = matchMedia("(pointer: coarse)").matches;
  const renderer = new THREE.WebGLRenderer({ antialias: !touch, alpha: true });
  renderer.setPixelRatio(Math.min(devicePixelRatio, touch ? 1.5 : 2));
  renderer.outputColorSpace = THREE.SRGBColorSpace;
  renderer.toneMapping = THREE.ACESFilmicToneMapping;
  renderer.toneMappingExposure = 0.85;
  el.appendChild(renderer.domElement);

  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(30, 1, 0.1, 100);

  // Reflections: a soft studio environment for the plastic and glass to catch.
  const pmrem = new THREE.PMREMGenerator(renderer);
  const env = pmrem.fromScene(new RoomEnvironment(), 0.04).texture;
  scene.environment = env;
  scene.environmentIntensity = 0.45;
  scene.add(new THREE.HemisphereLight(0xffffff, 0xb8b6d9, 0.5));
  const key = new THREE.DirectionalLight(0xfff4e0, 1.8);
  key.position.set(4, 6, 5);
  scene.add(key);

  // 90s plastic: satin, not matte. A fine moulded grain drives bump and roughness.
  const grainCanvas = document.createElement("canvas");
  grainCanvas.width = grainCanvas.height = 128;
  const g = grainCanvas.getContext("2d")!;
  const img = g.createImageData(128, 128);
  for (let p = 0; p < img.data.length; p += 4) {
    const v = 150 + Math.random() * 70;
    img.data[p] = img.data[p + 1] = img.data[p + 2] = v;
    img.data[p + 3] = 255;
  }
  g.putImageData(img, 0, 0);
  const grain = new THREE.CanvasTexture(grainCanvas);
  grain.wrapS = grain.wrapT = THREE.RepeatWrapping;
  grain.repeat.set(6, 6);

  const plastic = (color: number, roughness: number) =>
    new THREE.MeshPhysicalMaterial({
      color, roughness, roughnessMap: grain, bumpMap: grain, bumpScale: 0.6,
      clearcoat: 0.35, clearcoatRoughness: 0.35, sheen: 0.3, sheenRoughness: 0.6, envMapIntensity: 0.9,
    });
  const box = (w: number, h: number, d: number, m: T.Material, x = 0, y = 0, z = 0) => {
    const mesh = new THREE.Mesh(new THREE.BoxGeometry(w, h, d), m);
    mesh.position.set(x, y, z);
    return mesh;
  };

  // A soft contact shadow: a radial gradient on the floor, cheaper than real shadows and softer.
  const shadowCanvas = document.createElement("canvas");
  shadowCanvas.width = shadowCanvas.height = 64;
  const sg = shadowCanvas.getContext("2d")!;
  const grad = sg.createRadialGradient(32, 32, 0, 32, 32, 32);
  grad.addColorStop(0, "rgba(23,21,58,0.35)");
  grad.addColorStop(1, "rgba(23,21,58,0)");
  sg.fillStyle = grad;
  sg.fillRect(0, 0, 64, 64);
  const shadowTex = new THREE.CanvasTexture(shadowCanvas);
  const blob = (radius: number) => {
    const m = new THREE.Mesh(new THREE.PlaneGeometry(radius * 2, radius * 2), new THREE.MeshBasicMaterial({ map: shadowTex, transparent: true, depthWrite: false }));
    m.rotation.x = -Math.PI / 2;
    m.position.y = 0.002;
    return m;
  };

  // Frame a bounding sphere from a fixed direction; re-run on every resize.
  let framed: [T.Sphere, T.Vector3, number] | null = null;
  const aim = () => {
    if (!framed) return;
    const [sphere, view, tight] = framed;
    const { width, height } = el.getBoundingClientRect();
    renderer.setSize(width, height, false);
    camera.aspect = width / Math.max(height, 1);
    const vfov = THREE.MathUtils.degToRad(camera.fov);
    const hfov = 2 * Math.atan(Math.tan(vfov / 2) * camera.aspect);
    camera.position.copy(sphere.center).addScaledVector(view, (sphere.radius / Math.sin(Math.min(vfov, hfov) / 2)) * tight);
    camera.lookAt(sphere.center);
    camera.updateProjectionMatrix();
  };
  const fit = (sphere: T.Sphere, view: T.Vector3, tight = 0.86) => { framed = [sphere, view.clone().normalize(), tight]; aim(); };
  const ro = new ResizeObserver(() => { aim(); renderer.render(scene, camera); });
  ro.observe(el);

  // The loop only runs while the scene is on screen and the tab is visible. Panes slide by transform,
  // so a scene on another tab reads as off screen and stops too.
  let raf = 0, visible = false, last = 0, frame: ((t: number, dt: number) => boolean | void) | null = null;
  const tick = (now: number) => {
    raf = 0;
    if (!visible || document.hidden || !frame) { last = 0; return; }
    const dt = last ? Math.min((now - last) / 1000, 0.1) : 0;
    last = now;
    if (frame(now / 1000, dt) !== false) renderer.render(scene, camera);
    el.dataset.frames = String(Number(el.dataset.frames ?? 0) + 1); // for the off-screen check in the plan
    raf = requestAnimationFrame(tick);
  };
  const wake = () => { if (!raf && visible && !reduce) raf = requestAnimationFrame(tick); };
  const io = new IntersectionObserver(([e]) => { visible = e.isIntersecting; wake(); });
  io.observe(el);
  const onVis = () => wake();
  document.addEventListener("visibilitychange", onVis);
  const run = (f: (t: number, dt: number) => boolean | void) => {
    frame = f;
    if (reduce) { f(0, 0); renderer.render(scene, camera); } else wake();
  };

  const dispose = () => {
    cancelAnimationFrame(raf);
    io.disconnect();
    ro.disconnect();
    document.removeEventListener("visibilitychange", onVis);
    scene.traverse((o) => {
      if (o instanceof THREE.Mesh) { o.geometry.dispose(); (Array.isArray(o.material) ? o.material : [o.material]).forEach((mt) => { (mt as T.MeshStandardMaterial).map?.dispose(); mt.dispose(); }); }
    });
    grain.dispose(); shadowTex.dispose(); env.dispose(); pmrem.dispose(); renderer.dispose();
    renderer.domElement.remove();
  };

  return { THREE, renderer, scene, camera, reduce, touch, plastic, box, blob, fit, run, dispose };
}
export type Toy = Awaited<ReturnType<typeof toyStage>>;
```

```tsx
async function mount(el: HTMLElement, live: React.RefObject<{ hot: Prop | null; onHot: Props["onHot"]; onPick: Props["onPick"] }>) {
  const { toyStage } = await import("@/lib/toyStage");
  const toy: Toy = await toyStage(el);
  const { THREE, scene, camera, plastic, box, blob, reduce } = toy;
  const beige = plastic(0xcdbb94, 0.45), beigeDark = plastic(0xb3a27c, 0.55), ink = plastic(0x2a2760, 0.4);
  const desk = new THREE.Group();
  scene.add(desk);

  // Phone: a sloped base, a 4x3 keypad, the handset on its cradle, a coiled cord between them.
  const phone = new THREE.Group();
  phone.add(box(1.5, 0.35, 1.1, beige, 0, 0.175, 0));
  const slope = box(1.5, 0.12, 0.7, beigeDark, 0, 0.4, 0.15); slope.rotation.x = -0.25; phone.add(slope);
  const keys = new THREE.InstancedMesh(new THREE.BoxGeometry(0.16, 0.05, 0.12), beige, 12);
  const mx = new THREE.Matrix4();
  for (let i = 0; i < 12; i++) keys.setMatrixAt(i, mx.makeTranslation(-0.2 + (i % 3) * 0.2, 0.47 - Math.floor(i / 3) * 0.035, 0.32 - Math.floor(i / 3) * 0.15));
  phone.add(keys);
  const handset = new THREE.Group();
  handset.add(box(1.4, 0.16, 0.3, beige, 0, 0, 0));
  handset.add(box(0.34, 0.2, 0.36, beige, -0.6, -0.06, 0));
  handset.add(box(0.34, 0.2, 0.36, beige, 0.6, -0.06, 0));
  handset.position.set(0, 0.62, -0.25);
  phone.add(handset);
  // The cord: a helix wrapped along a sagging curve from the base to the handset's end.
  const along = new THREE.CatmullRomCurve3([new THREE.Vector3(-0.75, 0.2, 0.2), new THREE.Vector3(-1.2, 0.05, 0.6), new THREE.Vector3(-1.3, 0.3, -0.2), new THREE.Vector3(-0.75, 0.55, -0.25)]);
  const coil = (wob: number) => {
    const pts: T.Vector3[] = [];
    for (let i = 0; i <= 400; i++) {
      const u = i / 400, p = along.getPointAt(u), a = u * Math.PI * 2 * 26;
      pts.push(p.add(new THREE.Vector3(Math.cos(a) * 0.05, Math.sin(a) * 0.05 + Math.sin(u * 9 + wob) * 0.03 * Math.abs(Math.sin(wob)), 0)));
    }
    return new THREE.TubeGeometry(new THREE.CatmullRomCurve3(pts), 400, 0.012, 5);
  };
  const cord = new THREE.Mesh(coil(0), ink);
  phone.add(cord);
  phone.add(blob(1.1));
  phone.position.set(-2.4, 0, 0.2);
  phone.rotation.y = 0.35;
  desk.add(phone);

  // Printer: a dot-matrix body, a dark lid, tractor-feed paper with her name coming out the top.
  const printer = new THREE.Group();
  printer.add(box(2.0, 0.55, 1.3, beige, 0, 0.275, 0));
  printer.add(box(1.7, 0.08, 0.9, beigeDark, 0, 0.59, -0.1));
  printer.add(box(0.12, 0.05, 0.02, new THREE.MeshBasicMaterial({ color: 0x5be37d }), 0.8, 0.35, 0.66)); // power LED
```

```ts
// The Skills cabinet: one drawer per skill group, opened as far as the picked role used it.
// Even one chip opens a drawer to 35%, so "touched" always reads as open.
export type Drawer = { name: string; total: number; used: number; open: number; col: 0 | 1; row: number; wide: boolean };

export function drawers(layers: readonly { name: string; chips: readonly string[] }[], used: readonly string[], all: boolean): Drawer[] {
  return layers.map((l, i) => {
    const n = l.chips.filter((c) => used.includes(c)).length;
    return {
      name: l.name,
      total: l.chips.length,
      used: n,
      open: all || !n ? 0 : 0.35 + (0.65 * n) / l.chips.length,
      wide: i === 0,
      row: i === 0 ? 0 : 1 + Math.floor((i - 1) / 2),
      col: (i === 0 ? 0 : (i - 1) % 2) as 0 | 1,
    };
  });
}
```

```tsx
  const ray = new THREE.Raycaster(), ndc = new THREE.Vector2();
  let over: number | null = null;
  const onMove = (e: PointerEvent) => {
    const r = el.getBoundingClientRect();
    ndc.set(((e.clientX - r.left) / r.width) * 2 - 1, -((e.clientY - r.top) / r.height) * 2 + 1);
    ray.setFromCamera(ndc, camera);
    const i = slots.findIndex((s) => ray.intersectObject(s.g, true).length);
    const next = i < 0 ? null : i;
    if (next !== over) { over = next; live.current.onHover(next); }
  };
  const onLeave = () => { if (over !== null) { over = null; live.current.onHover(null); } };
  el.addEventListener("pointermove", onMove);
  el.addEventListener("pointerleave", onLeave);

  const sphere = new THREE.Box3().setFromObject(cab).getBoundingSphere(new THREE.Sphere());
  toy.fit(sphere, new THREE.Vector3(-1.4, 1.1, 4.2), 0.78);

  const settle = (dt: number) => {
    const { state, used, nudge } = live.current;
    if (used !== lastUsed) { paint(used); lastUsed = used; }
    let moving = false;
    slots.forEach((s, i) => {
      const to = state[i].open * (D * 0.7) + (nudge === i || over === i ? 0.08 : 0);
      s.open = reduce ? to : s.open + (to - s.open) * (1 - Math.exp(-dt * 6));
      if (Math.abs(to - s.open) > 0.001) moving = true;
      s.g.position.z = s.open;
    });
    return moving;
  };
  // Only render while something is sliding (or on the first frame): the cabinet is otherwise still.
  let boot = true;
  toy.run((_, dt) => { const m = settle(dt) || boot; boot = false; return m; });
  const still = reduce ? setInterval(() => { settle(0); toy.renderer.render(scene, camera); }, 120) : 0;

  return () => { clearInterval(still); el.removeEventListener("pointermove", onMove); el.removeEventListener("pointerleave", onLeave); part.dispose(); toy.dispose(); };
}
```
